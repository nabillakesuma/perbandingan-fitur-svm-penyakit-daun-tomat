
# Notebooks

Folder ini berisi notebook penelitian klasifikasi penyakit daun tomat menggunakan algoritma Support Vector Machine (SVM).

## Daftar Notebook

- `SVM_Bertahapp.ipynb`: Notebook eksperimen yang mencakup proses ekstraksi fitur, pelatihan model SVM, optimasi parameter, dan evaluasi performa.
- `UI_Aplikasi_Perbandingan.ipynb`: Notebook pendukung pengembangan dan pengujian aplikasi klasifikasi penyakit daun tomat.
