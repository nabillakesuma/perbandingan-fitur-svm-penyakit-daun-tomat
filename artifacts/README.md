
# Artifacts

Folder ini berisi model hasil pelatihan dan komponen pendukung yang digunakan dalam proses inferensi klasifikasi penyakit daun tomat.

Terdapat tiga konfigurasi model:

- M1: SVM + Raw Pixel
- M2: SVM + Raw Pixel + GLCM
- M3: SVM + Raw Pixel + GLCM + HOG + LBP

Model dan komponen pendukung digunakan oleh aplikasi untuk melakukan prediksi terhadap citra daun tomat.
